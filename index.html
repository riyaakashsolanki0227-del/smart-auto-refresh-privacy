Smart Auto Refresh – Privacy Policy

Last updated: October 29, 2026

Smart Auto Refresh is a Chrome extension that helps users refresh selected browser tabs at user-configured intervals and manage refresh-related settings.

1. Information We Handle

The extension may access information about open tabs, such as tab URLs and titles, so it can display tabs to the user and apply refresh controls to tabs the user selects. It may also observe page interaction locally when its activity-aware controls are enabled.

These details are used to provide the extension's core features. The extension is designed to process this information locally in the browser and does not intentionally send it to the developer or to an external server.

2. Settings Stored Locally

The extension may store user-selected tabs, refresh intervals, timer preferences, and other extension settings in Chrome's local extension storage so the settings can persist between popup sessions. This information remains in the user's browser unless the extension's implementation or the user's actions cause otherwise.

3. Collection, Sale, and Sharing

Smart Auto Refresh does not sell personal information. The extension does not intentionally transmit tab URLs, browsing activity, page content, or locally stored settings to the developer or third parties. The extension is not designed to use information for advertising, creditworthiness decisions, or lending purposes.

4. Website Content and Refreshing

When the user chooses to refresh a tab, Chrome reloads the selected website. The website itself may receive requests and process information under its own privacy policy. Smart Auto Refresh does not control how third-party websites handle information.

Some browser pages are restricted by Chrome and cannot be refreshed by extensions. Refresh timing may vary because of Chrome scheduling and website behavior.

5. Permissions

The extension uses browser permissions needed for its core functionality, such as saving settings, scheduling refresh tasks, identifying tabs, and performing supported page actions. Access is intended to support the extension's stated purpose.

6. Data Retention and Deletion

Extension settings stored locally can generally be cleared by removing the extension or clearing its stored data through Chrome. The extension does not maintain a developer-operated account or server-side data store as part of its intended operation.

7. Children's Privacy

Smart Auto Refresh is a general-purpose productivity tool and is not designed to collect personal information from children.

8. Changes to This Policy

This policy may be updated if the extension's features or data practices change. The latest version should be published at the same public URL.
